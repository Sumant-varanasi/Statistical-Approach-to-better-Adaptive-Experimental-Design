## Reproducibility across machines

19 campaigns were run on both the laptop and the HPC with the same code and seed. In 10 the settings chosen agree to 1e-6 throughout (only the last digits of the numbers differ); in 9 the two machines' rounding tipped a close decision and the campaigns went different ways from some run on (median difference in profit earned 7, largest 172):

- complex/smart_v6_nogp_missing_E_s8_b25.npz: from run 8, earned -172 (laptop minus HPC)
- complex/smart_v6_nogp_s8_b25.npz: from run 25, earned +0 (laptop minus HPC)
- complex/smart_v6_nonn_missing_E_s8_b25.npz: from run 7, earned -46 (laptop minus HPC)
- complex/smart_v7_norevise_missing_E_s8_b25.npz: from run 7, earned -56 (laptop minus HPC)
- complex_deact/smart_v6_nogp_missing_E_s7_b25.npz: from run 19, earned -0 (laptop minus HPC)
- complex_deact/smart_v6_nogp_missing_E_s8_b25.npz: from run 16, earned -22 (laptop minus HPC)
- complex_deact/smart_v6_nonn_missing_E_s8_b25.npz: from run 7, earned -7 (laptop minus HPC)
- complex_deact/smart_v7_norevise_missing_E_s8_b25.npz: from run 7, earned -6 (laptop minus HPC)
- complex_deact/smart_v7_s7_b25.npz: from run 22, earned +0 (laptop minus HPC)

A campaign is reproducible on one machine; across machines, campaigns whose model is wrong can diverge. The same seed still gives every method the same screening runs and the same reactor noise, so the pairing holds. Each campaign is used once (the HPC copy where there are two).
